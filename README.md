# GeneOriginAnalyzer

Сравнительно-геномный анализ потенциальных orphan genes у Escherichia coli.

Исследованы четыре штамма E. coli (MG1655, W3110, REL606, Sakai) и E. albertii в качестве внешнего сравнительного таксона.

Работа включает:
- первичный поиск потенциальных orphan genes;
- сравнение с протеомом и геномом E. albertii;
- кластеризацию белков в ортогруппы с OrthoFinder;
- анализ геномного окружения и синтении;
- разбор четырёх кандидатов и одного положительного контроля;
- построение филогеномного видового дерева с IQ-TREE.

## Основные результаты

17 891 белок четырёх штаммов E. coli → 1329 предварительных кандидатов → 1160 кандидатов длиной не менее 50 aa → 660 белков без обнаруженного убедительного соответствия в использованном сравнении с E. albertii.

Эти 660 белков являются кандидатами для дальнейшего анализа, а не доказанными de novo-генами.

## Ограничения

Отсутствие обнаруженного гомолога не доказывает de novo-происхождение. Филогеномное видовое дерево не является генным деревом кандидата.
