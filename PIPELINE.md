# GeneOriginAnalyzer — pipeline моего анализа

## 1. Цель

Поиск потенциальных orphan genes у Escherichia coli и предварительная оценка возможных сценариев их эволюционного происхождения.

Рассматриваемые сценарии:
- вертикальное наследование;
- дупликация и дивергенция;
- горизонтальный перенос генов (HGT);
- возможное возникновение de novo из некодирующей последовательности;
- древнее происхождение с последующей сильной дивергенцией;
- неопределённое происхождение.

Отсутствие обнаруженного гомолога само по себе не доказывает de novo-происхождение.

## 2. Набор данных

Использованы пять протеомов:

| Организм / штамм | Белков |
|---|---:|
| E. coli MG1655 | 4300 |
| E. coli W3110 | 4227 |
| E. coli REL606 | 4209 |
| E. coli Sakai | 5155 |
| E. albertii | 4314 |
| **Всего** | **22205** |

Четыре штамма E. coli содержат суммарно 17 891 белок.
E. albertii использована как внешний сравнительный таксон.

Основные входные файлы:
`data/processed/orthofinder_input/`

## 3. Первичный поиск потенциальных orphan genes

### 3.1. Поиск сходства между белками E. coli

Проведено сравнение белковых последовательностей четырёх штаммов E. coli.
На этом этапе отбирались белки, для которых не было обнаружено гомологов в остальных исследованных штаммах при использованных параметрах поиска.

Результат первичного отбора:
- 17 891 исходный белок;
- 1329 предварительных кандидатов без обнаруженных гомологов;
- 1160 кандидатов длиной не менее 50 аминокислот.

Важно: это предварительные кандидаты, а не доказанные orphan genes.

### 3.2. Сравнение с E. albertii

Кандидаты дополнительно сравнивались с белковым набором и геномом E. albertii.

Получены следующие категории:
- 402 кандидата с белковыми совпадениями;
- 98 случаев с совпадениями на уровне генома, но без соответствующего белкового совпадения;
- 660 белков, для которых не было обнаружено убедительного соответствия в использованных поисках.

Число 660 обозначает кандидатов без обнаруженного соответствия в выбранном сравнительном наборе и при использованных параметрах. Оно не является числом доказанных de novo-генов.

## 4. Анализ ортогрупп с помощью OrthoFinder

Для пяти протеомов выполнен OrthoFinder.

Использованная команда:

```bash
orthofinder \
  -f data/processed/orthofinder_input \
  -o results/orthofinder_run2 \
  -S diamond \
  -M msa \
  -A mafft \
  -T fasttree \
  -t 4 \
  -a 4
```

Основной каталог результатов:
`results/orthofinder_run2/Results_Nov12/`

Получено:
- 4598 ортогрупп;
- таблицы распределения генов по ортогруппам;
- список однокопийных ортологов;
- список генов, не отнесённых OrthoFinder к ортогруппам;
- видовое дерево OrthoFinder.

Для дальнейшего построения суперматрицы использовано 2879 однокопийных ортогрупп по фактическому числу записей в использованном списке. В раннем отчёте OrthoFinder встречалось значение 2878; при описании результата следует ориентироваться на фактически использованный список и созданную суперматрицу.

Наличие гена в одной ортогруппе само по себе не доказывает ортологию во всех случаях: необходимо учитывать качество и длину выравнивания, сходство последовательностей и возможные паралогии.

## 5. Анализ геномного окружения и синтении

Для выбранных кандидатов изучалось локальное геномное окружение:
- аннотированные соседние CDS;
- расстояния до соседних генов;
- наличие мобильных генетических элементов;
- фаговые и другие функциональные контексты;
- сохранность фланкирующих участков у E. albertii;
- возможные ORF в соответствующих интервалах генома.

Использовались результаты и таблицы из:
`results/synteny/`

Дополнительно исследовались интервалы генома E. albertii, фланкирующие белки и локусы, связанные с T6SS.

Геномное окружение помогает сформировать гипотезу о возможном контексте гена, но само по себе не доказывает механизм его происхождения.

## 6. Углублённый анализ выбранных белков

Для детального рассмотрения выбраны четыре потенциальных кандидата и один положительный контроль.

### NP_310248.1 — E. coli Sakai, 289 aa

Белок расположен в области, обогащённой последовательностями, связанными с IS629 и транспозазами.
Обнаружено короткое сходство с NP_304549.1: 95,294% идентичности на участке 85 aa, покрывающем 29,4% длины исследуемого белка.
OrthoFinder поместил три белка Sakai в OG0004120, однако длины последовательностей существенно различаются.

Интерпретация: возможная связь с мобильным генетическим контекстом; дупликация и принадлежность самого белка к транспозазам не доказаны.

### NP_303550.1 — E. coli Sakai, 132 aa

При сравнении с белками четырёх штаммов E. coli не обнаружено негомологичных совпадений, кроме самого белка.
Белок не был отнесён OrthoFinder к ортогруппе (OG0005127).
Расположен в фаг-ассоциированном участке генома, рядом с генами, связанными с холином, эндолизином и терминазой.

Интерпретация: кандидат, связанный с фаговым геномным контекстом. Это не доказывает горизонтальный перенос или конкретное происхождение белка.

### NP_308259.1 — E. coli Sakai, 74 aa

Белок расположен между impC и impB в области T6SS.
В соответствующем участке E. albertii найден короткий ORF467 длиной 58 aa между tssC и tssB.
Локальное выравнивание выявило короткое сходство, но при поиске по всему протеому E. albertii убедительный гомолог не обнаружен.
Белок не отнесён OrthoFinder к ортогруппе (OG0005146).

Интерпретация: интересный малый ORF в аналогичном функциональном локусе; гомология и эволюционное родство пока не подтверждены.

### ACT39985.1 — E. coli REL606, 58 aa

В соответствующем интервале E. albertii найден ORF с коротким совпадением: 29 aa и 86,2% идентичности.
Совпадение частичное; соответствующий участок перекрывается с аннотированной CDS сериновой гидролазы.
OrthoFinder включил белок в OG0003699 вместе с более длинными последовательностями, однако совпадение покрывает только небольшую часть длинных белков.

Интерпретация: возможны фрагментация белка, особенности аннотации или артефакт. Происхождение остаётся неопределённым.

### NP_310689.1 — E. coli Sakai, 585 aa (положительный контроль)

Белок является флагеллином.
Для него обнаружены гомологи, в том числе в E. albertii.
Он входит в OG0003299; длины и выравнивание последовательностей согласуются с принадлежностью к общей белковой семье.

Интерпретация: это не orphan gene. Контроль показывает, что результаты первичного отбора требуют дополнительной проверки и что отсутствие совпадения на раннем этапе не всегда означает отсутствие гомологии.

## 7. Филогеномный анализ

Для оценки родства исследованных организмов построена суперматрица из 2879 однокопийных ортогрупп.

Файл суперматрицы:
`results/phylogeny/single_copy_supermatrix.faa`

Манифест использованных ортогрупп:
`results/phylogeny/gene_manifest.tsv`

Размер суперматрицы — 931 952 позиции выравнивания.

Построено филогеномное видовое дерево с IQ-TREE 3:

```bash
iqtree \
  -s results/phylogeny/single_copy_supermatrix.faa \
  -m MFP \
  -B 1000 \
  --alrt 1000 \
  -bnni \
  -T 4 \
  --seed 12345 \
  --prefix results/phylogeny/species_tree
```

Выбранная модель: JTT+F+I+R10.
Для внутренних ветвей получены значения поддержки SH-aLRT/UFBoot 100/100.

Это видовое (филогеномное) дерево, построенное по набору однокопийных ортогрупп. Оно описывает отношения между исследованными организмами, а не эволюционную историю каждого отдельного кандидата.

## 8. Ограничения анализа

- Отсутствие BLAST/DIAMOND-совпадения не доказывает de novo-происхождение.
- Нераспределение в ортогруппу не доказывает, что белок является orphan gene.
- Короткое совпадение может быть случайным или отражать общий небольшой домен.
- Геномный контекст (фаговый, мобильный элемент, T6SS) не доказывает HGT.
- Видовое дерево не заменяет генное дерево.
- Для большинства выбранных кандидатов не удалось сформировать надёжные наборы гомологов для построения индивидуальных генных деревьев.
- Удалённый BLAST по базе NCBI не был завершён для всех кандидатов; его результаты нельзя считать систематическим этапом анализа.

## 9. Общая логика интерпретации

Результаты рассматриваются на нескольких уровнях:
1. Наличие или отсутствие обнаруживаемого сходства.
2. Распределение белков между исследованными геномами.
3. Принадлежность к ортогруппам и качество соответствующих выравниваний.
4. Сохранность геномного окружения и синтении.
5. Контекст локуса и возможные функциональные ассоциации.
6. Филогеномный контекст исследованных организмов.

На основании совокупности признаков формируются предварительные гипотезы об эволюционном происхождении. Ни один из рассмотренных кандидатов не следует объявлять доказанным de novo-геном без дополнительных данных.
